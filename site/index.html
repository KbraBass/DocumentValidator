Validate e-invoices in your browser

XSD structure + Schematron business rules for every format in phive-rules — EN 16931, Peppol BIS, XRechnung, ZUGFeRD / Factur-X, and more.

Pick a format (or leave it on Auto-detect) and drop one or more XML documents below. The page runs both validation layers on each — XSD bundle (structure) and the format's Schematron (business rules) — and shows the results inline.

Documents never leave the browser. Every byte you pick is processed entirely client-side — xmllint-wasm (libxml2) for XSD, Saxon-JS HE for Schematron. The only network requests are the initial fetch of the runtimes and the rule assets themselves. This page makes no upload.
Caveat: browser extensions. Like any web page, content you load here is visible to browser extensions you have installed (ad blockers, translators, password managers, etc.), which could read or exfiltrate it. That is outside this page's control and we are not responsible for it. For sensitive production documents, use a browser with no extensions or a private / incognito window (where extensions are disabled by default).

How auto-detect works

The format is inferred from the document's root element; for UBL and CII documents the Customization ID (cbc:CustomizationID, or for CII ram:GuidelineSpecifiedDocumentContextParameter/ram:ID) narrows it to the exact rule set. Auto-detect always selects the latest shipped version of the matching specification. The most specific rule wins, e.g. an XRechnung document is detected as XRechnung rather than plain EN 16931.

Bulk runs

Drop a whole batch at once — the XSD layer runs in a pool of Web Workers (one per CPU core), so large batches scale on powerful machines; the Schematron layer runs on the main thread (Saxon-JS needs the DOM, which Web Workers don't provide). The Analytics tab then turns the batch into a printable, filterable dashboard.

Validating thousands of files is still memory-intensive in a browser. For very large batches the CLI validator runs the same rules (lxml + SaxonC HE) in a long-lived process:

uv run --with lxml --with saxonche --with pyyaml python tools/validate.py doc.xml

Rule assets derived from phax/phive-rules (see validation-assets/manifest.json for the pinned tag). Schematron runs on Saxon-JS HE; XSD on libxml2-wasm. This page ships no analytics and makes no third-party calls beyond the web font.
