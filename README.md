# DocumentValidator
Simple web-based Electronic Document Validation tool that uses Phax' phive-rules on a web front-end.
Hosted as GitHub Page on https://kbrabass.github.io/DocumentValidator/site/

The source of this service is described on https://peppol.helger.com/public/menuitem-validation-ws2  
The original validation engine is on https://github.com/phax/phive  

My code is just a web version that runs entirely on the browser with no data being sent to the server.
It does the same job as [ecosio](https://ecosio.com/en/peppol-and-xml-document-validator/), but with the following added features or benefits:
- Support for bulk validation
- Data analysis dashboard for bulk validations
- Zero data upload to server
- No cookies
- Parallel processing for faster bulk validations
